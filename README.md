# SWYNEX-Exploratory-Data-Analysis
#  Customer Data Analytics Dashboard 

##  Project Overview

The **Customer Data Analytics Dashboard** is a Python-based desktop application developed to perform Exploratory Data Analysis (EDA) on customer data.

It uses Python, Pandas, Matplotlib, Seaborn and Tkinter to analyze customer demographics, purchasing behaviour, signup trends and data quality.

The application provides a scrollable dashboard where users can explore multiple visualizations and customer records in one window.

##  Project Objectives

- Analyze customer demographics and purchasing patterns.
- Understand customer distribution by age, gender, city and country.
- Identify popular product categories and purchasing channels.
- Analyze monthly customer signup trends.
- Detect missing values and potential purchase outliers.
- Present insights through a graphical desktop dashboard.

##  Dashboard Features

### 2. Customer Demographics

- Gender distribution
- Customers by country
- Top 10 cities by purchase

### 3. Purchase Analysis
- Purchase by category
- Purchase by purchasing channel
- Top 10 cities by purchase amount
- Purchase amount distribution

### 4. Customer Trends
- Monthly customer signup analysis
- Age vs. purchase amount relationship
- Customer age group analysis

### 5. Data Quality Analysis

- Purchase amount outlier detection

### 6. Customer Dataset
- Complete customer data table
- Vertical and horizontal scrolling
- Customer records displayed directly in the dashboard
